# Beginner Projects

### 1. Word Counter

Counts the number of words, characters, sentences, and paragraphs in a text. Helps you learn text processing and string manipulation.

### 2. Text Cleaner

Removes unwanted characters, punctuation, HTML tags, emojis, and stopwords from raw text. Teaches NLP preprocessing techniques.

### 3. Regex Extractor

Uses regular expressions to extract patterns such as emails, phone numbers, URLs, dates, or hashtags from text. Builds pattern-matching skills.

### 4. Resume Parser

Extracts information like name, email, skills, education, and experience from resumes automatically. Introduces Named Entity Recognition (NER).

### 5. Sentiment Analyzer

Determines whether a piece of text expresses positive, negative, or neutral sentiment. Commonly used for product reviews and social media analysis.

### 6. Spam Detection

Classifies emails or messages as spam or legitimate (ham). Teaches text classification using machine learning.

---

# Intermediate Projects

### 7. News Summarizer

Generates a shorter version of a news article while preserving key information. Introduces text summarization techniques.

### 8. FAQ Chatbot

Answers predefined user questions by matching them with a stored knowledge base. Helps learn intent detection and retrieval methods.

### 9. Topic Modeling

Discovers hidden topics within a collection of documents without labeled data. Useful for analyzing large text datasets.

---

# Advanced Projects

### 10. RAG Chatbot (Retrieval-Augmented Generation)

Retrieves relevant information from documents and uses an LLM to generate accurate answers. Widely used in modern AI assistants.

### 11. AI Search Engine

Performs semantic search by understanding meaning instead of exact keywords. Uses embeddings and vector databases.

### 12. Fine-Tuned LLM

Trains or adapts a pre-trained language model on a specific dataset to improve performance for a particular domain or task.

### 13. Multi-Agent Assistant

Multiple AI agents collaborate to solve complex tasks, where each agent has a specialized role such as research, coding, planning, or reviewing.
